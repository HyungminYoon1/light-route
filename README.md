# LIGHT ROUTE — 빛의 미궁

> 배포 단계 안내(2026-10-09): 로컬 검토 후 사용자의 공개 배포 승인을 받았습니다. 아래 LOCAL ONLY/NOT_RUN은 배포 전 검토 기록입니다. 승인 후 실제 공개 결과는 [통합 배포 검증](https://github.com/HyungminYoon1/web-lab/blob/main/docs/verification.md)의 최신 배포 절에서 따로 확인합니다.

[사이트 열기](https://hyungminyoon1.github.io/light-route/)

8×8 격자에서 거울·분기·색 변환기를 조작하는 6개 장, 18단계 퍼즐입니다. 목표와 필수 경유지를 모두 켜면서 금지 센서는 피해야 합니다. 아래 내용은 로컬 v2 구현 기준이며 공개 사이트 반영 여부는 [검증 기록](docs/verification.md)에서 구분합니다.

- 매번 다른 경로 형태: 4×4 논리 격자에서 자기 교차 없는 경로 트리를 만들고 8×8 보드로 옮깁니다. 예전의 네 거울 배치를 반복하지 않습니다.
- 초반 4–6개 이상, 후반 13개 이상의 정답 경로 장치에 별도 방해 장치를 추가합니다. 모든 장치를 사용할 필요는 없습니다.
- 회전 즉시 광선·목표·경유지·금지 센서 상태 갱신. 거울과 분기는 글자 대신 SVG 대각선으로 표시합니다.
- 최근 256번 회전 되돌리기, 처음 배치, 한 단계 힌트, 완료 점수·별·장 완료 피드백.
- 새 퍼즐 코드와 동일 코드 재현, 단계 자유 선택.
- A/C 문자와 색을 함께 표시하여 색만으로 규칙을 전달하지 않음.
- Tab/Enter/Space 및 같은 행·열의 화살표 이동, 회전 후 초점 유지, 좌표·방향·색 이름과 텍스트 경로 제공.
- 정답 배치를 먼저 만들고 실제 광선 추적으로 모든 조건을 검증한 뒤 섞습니다. 생성 시도는 최대 128번이며 실패하면 검증된 대체 경로를 사용합니다.

| 장 | 단계 | 도전 조건 |
| --- | --- | --- |
| 반사의 설계 | 1–3 | 4회 이상의 방향 전환, 긴 우회와 방해 거울 |
| 필수 경유지 | 4–6 | 빛을 멈추지 않는 체크포인트 2–3개도 통과 |
| 분기 회로 | 7–9 | 직진·반사 빛으로 2–3개 목표를 동시에 연결 |
| 색의 순서 | 10–12 | 목표와 경유지마다 A/C를 맞추는 변환 순서 |
| 안전한 빛 | 13–15 | 세 목표, 네 경유지, 금지 센서 회피 |
| 마스터 회로 | 16–18 | 네 목표와 모든 제약의 결합, 17–18단계의 고정 거울 |

## 규칙과 저장 범위

기본 1,000점에서 조작 1회마다 15점, 힌트 1회마다 120점 차감하고 최소 20점입니다. 되돌리기도 조작 횟수에 포함합니다. 별은 점수 구간이며 수학적으로 증명한 최소 이동 수가 아닙니다. 처음 배치는 조작·힌트를 초기화합니다. 힌트는 방해 장치와 고정 거울을 제외한 한 가지 검증된 해답으로 안내하며 다른 유효한 해답도 완료로 인정합니다.

목표·벽·금지 센서는 광선을 멈춥니다. 경유지는 해당 색이 통과해야 하며 색 지정이 없으면 어느 색도 허용합니다. 목표를 모두 켜도 경유지를 놓치거나 금지 센서를 켜면 완료되지 않습니다. 광선은 칸×방향×색의 512개 상태 안에서 처리하며 분기 합류와 실제 순환을 구분합니다.

최고 기록은 기존 브라우저 저장 영역 안에서 버전·코드·단계별로 구분하며 이전 기록을 포함해 최대 120개 보관합니다. v1 기록을 v2 점수로 표시하지 않습니다. 같은 코드도 버전이 달라지면 배치가 달라집니다. 기록 삭제는 이전 버전 기록도 포함합니다.

## 실행과 배포

Node.js 22 이상, 런타임 외부 의존성 없음.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 loopback에서 `dist/`만 제공합니다. `main`에 푸시하면 고정 SHA Actions가 시험·정적 검사 후 `dist/`를 GitHub Pages에 배포합니다. 저장소 Pages의 배포 소스는 GitHub Actions입니다.

## 기록과 개인정보

기록은 이 브라우저에만 저장하며 삭제할 수 있습니다. 계정, 분석 도구, 외부 AI API, 클라우드 저장, 전체 사용자 랭킹은 구현하지 않았습니다. CSP가 런타임 외부 연결을 막습니다. 공개 저장소에 정답·게임 규칙이 포함되므로 시험/공식 경쟁 판정 시스템이 아닙니다.
