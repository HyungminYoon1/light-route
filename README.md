# LIGHT ROUTE — 빛의 미궁

[사이트 열기](https://hyungminyoon1.github.io/light-route/)

8×8 격자에서 거울을 회전하고 광선을 분기하거나 색을 바꾸어 모든 목표를 켜는 12단계 퍼즐입니다.

- 거울 반사 → 여러 번 꺾기 → 광선 분기 → A/C 색 변환으로 규칙 확장.
- 회전 즉시 광선 경로와 도달한 목표 수 갱신.
- 되돌리기, 처음 배치, 한 단계 힌트, 완료 점수·별 표시.
- 새 퍼즐 코드와 동일 코드 재현, 단계 자유 선택.
- A/C 문자와 색을 함께 표시하여 색만으로 규칙을 전달하지 않음.
- 정답 배치를 먼저 만들고 실제 광선 추적으로 검증한 뒤 섞는 생성 방식.

## 규칙과 저장 범위

기본 1,000점에서 조작 1회마다 15점, 힌트 1회마다 120점 차감하고 최소 20점입니다. 되돌리기도 조작 횟수에 포함합니다. 별은 점수 구간이며 수학적으로 증명한 최소 이동 수가 아닙니다. 광선의 반복 상태와 최대 처리량을 제한해 분기·순환이 브라우저를 멈추지 않게 합니다. 최고 기록은 코드·단계별 최대 120개 보관합니다.

## 실행과 배포

Node.js 22 이상, 런타임 외부 의존성 없음.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 loopback에서 `dist/`만 제공합니다. `main`에 푸시하면 고정 SHA Actions가 시험·정적 검사 후 `dist/`를 GitHub Pages에 배포합니다. 저장소 Pages의 배포 소스는 GitHub Actions입니다.

## 기록과 개인정보

기록은 이 브라우저에만 저장하며 삭제할 수 있습니다. 계정, 분석 도구, 외부 AI API, 클라우드 저장, 전체 사용자 랭킹은 구현하지 않았습니다. CSP가 런타임 외부 연결을 막습니다. 공개 저장소에 정답·게임 규칙이 포함되므로 시험/공식 경쟁 판정 시스템이 아닙니다.
